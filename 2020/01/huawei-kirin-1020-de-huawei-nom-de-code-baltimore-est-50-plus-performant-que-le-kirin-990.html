Huawei Kirin 1020 de Huawei, nom de code Baltimore est 50% plus performant que le Kirin 990

7 janvier 2020NewsPuces et chipsetsHuawei

Huawei a lancé les processeurs Kirin 990 et Kirin 990 5G l'année dernière (2019), et ils se sont révélés impressionnants. Ce dernier était le tout premier SoC équipé de la technologie 5G lancé sur le marché, avec 10,3 milliards de transistors et la technologie EUV de 7 nm. Cependant, l'architecture CPU / GPU du Kirin 990 n'a reçu aucune mise à niveau importante, mais cela va changer avec le prochain SoC Kirin 1020.

Les dernières nouvelles montrent que le chipset Huawei Kirin 1020 porte le nom de code "Baltimore". Ce n'est pas surprenant, car les puces de Huawei ont toujours été nommées d'après les villes. Nous savons également que le processeur sera construit avec le processus 5 nm de TSMC pour une meilleure efficacité énergétique et des performances plus stables. Le plus gros changement vient cependant avec les cœurs CPU.

Le Kirin 1020 utilisera également les nouveaux cœurs Cortex-A78 en sautant les cœurs A77 que vous pouvez trouver sur d'autres SoC bien connus comme le MediaTek 1000 Dimensity. Par rapport au Cortex-A76 du Kirin 990, la nouvelle architecture de base permettra au Kirin 1020 d'améliorer facilement les performances de 50% par rapport à son prédécesseur.

C'est une mise à niveau de taille par rapport à ce qui était déjà une puce assez rapide. De plus, cela donne à Huawei le dessus sur d'autres concurrents comme le MediaTek, qui comptent toujours sur les cœurs Cortex-A77 pour les performances. Rien n'a été divulgué concernant le GPU, mais nous espérons que nous pouvons nous attendre à une mise à niveau similaire...
