Comment supprimer les applications préinstallées sur un Smartphone Android ?

28 février 2023ApplicationsSmartphones

Tous les appareils et notamment les mobiles fonctionnant sous Android arrivent avec un certain nombre d’applications préinstallées. En effet, pour promouvoir certains logiciels, les constructeurs de téléphone mobile et Google les imposent sur leurs appareils et contraignent les utilisateurs à les garder. Une partie d’entre eux sont bien sûr nécessaires et essentiels au bon fonctionnement du Smartphone comme ceux qui permettent de gérer les messages, les appels, le navigateur web…mais d’autres ne servent strictement à rien ; pire ils envahissent, encombrent et occupent de la place inutilement dans la mémoire rendant votre téléphone plus lourd et parfois même moins performant.

Mais ce n’est pas tout, le grand souci de ces applications préinstallées appelées également "bloatwares" est qu’elles ne peuvent pas être supprimées en suivant le processus habituel de désinstallation. Elles ne contiennent pas de bouton ou d’option de suppression comme les autres App. Heureusement, des solutions existent pour se débarrasser de ces logiciels en les masquant ou en les désinstallant mais avant de les envisager, il est conseillé de prendre le temps de vérifier que leur absence n’interférera pas dans le fonctionnement de votre mobile ou d’une autre application. Ainsi une fois désactivées, les App en question disparaissent de votre tiroir d'applications, cessent de recevoir des mises à jour et ne fonctionnent plus silencieusement en arrière-plan. De plus, toutes les app qui dépendent de l'application désactivée cesseront de fonctionner. Si vous désactivez les services Google Play, par exemple, plusieurs fonctions de votre mobile tomberont en panne, il vous faudra alors réinitialiser votre appareil pour tout rétablir.

Désactiver des Apps via les Paramètres

Certains fabricants de Smartphones vous permettent de désactiver les applications préinstallées via les paramètres. Cette méthode ne permettra pas la suppression totale des applications, mais celles-ci cesseront cependant de fonctionner en arrière-plan et n'apparaîtront plus dans le tiroir de vos applications.

Pour exécuter cette méthode, il vous suffit d’aller dans les "Paramètres", d’accéder à l’onglet "Général" puis de sélectionner "Applications et notifications". Là, vous aurez accès à la liste de toutes les applications. Choisissez ensuite celle que vous souhaitez désactiver et appuyez sur le bouton "Désactiver" ou "Forcer l’arrêt". Cette méthode n’est pas possible sur tous les appareils Android. Dans certains, le bouton de désinstallation est grisé et n’autorise donc pas la suppression de l’application.

Dans le cas contraire, le système vous avertira que la désactivation de cette App pourrait affecter le fonctionnement d’autres programmes. Parfois, cela peut être vrai, mais la plupart du temps, vous n’aurez aucun souci.

Désinstallez les applications via le Google Play Store

Si vous préférez ne pas utiliser l'option "Paramètres", sachez qu’une autre méthode permet de désactiver les applications préinstallées sur votre mobile. Vous pouvez ainsi le faire assez rapidement via le Google Play Store.

Pour cela, il vous suffit d’ouvrir le menu de la Play Store de Google. Cliquez dur l’onglet "Mes applications et jeux", puis sur "Installer". Cette action permettra d’ouvrir le menu des applications installées sur votre Smartphone. Il ne vous restera alors plus qu’à appuyer sur l'App dont vous n’avez pas besoin et que vous souhaitez supprimer pour être redirigé vers la page qui lui est dédiée sur Google Play Store. Là, cliquez sur "Désinstaller" pour vous débarrasser de ce logiciel inutile.

Notez toutefois qu’avec cette méthode qui passe par la Play Store, "désinstaller" une App ne signifie pas la faire disparaitre complétement de votre mobile mais seulement de la désactiver ou désinstaller ses mises à jour. Pour cela, vous allez devoir recourir à un processus un peu plus complexe en utilisant Android Debug Bridge.

Utiliser Android Debug Bridge

Si vous ne voulez pas vous contenter d’une désactivation et que vous voulez supprimer totalement une application préinstallée de votre Smartphone Android, nous vous recommandons d’utiliser Android Debug Bridge. Ce programme vous aide à supprimer complètement l’application de votre appareil.

Pour l’utiliser, vous devez commencer par l’installer sur votre ordinateur. Vous devez ensuite activer "Options de développement" sur votre téléphone. Une fois activé, accédez à l'option développeur, faites défiler la liste et activez le "débogage USB". Connectez votre mobile à votre PC via un câble USB et lorsque vous y êtes invité, changez le mode "charge uniquement" en mode "transfert de fichiers (MTP)".

Tapez la commande appareils adb pour démarrer adb et vérifiez que le téléphone est connecté. Si vous voyez une entrée répertoriée dans la section "Liste des appareils", votre appareil est connecté. Là, vous pourrez démarrer le shell adb "coque adb" et répertorier tous les packages installés sur le téléphone "paquets de liste pm". Recherchez le nom de l'application que vous souhaitez désinstaller ou aller simplement dans Google Play Store sur votre navigateur et recherchez l'application. Vérifiez l'URL du nom du package et saisissez la commande de désinstallation "pm uninstall -k --user 0 nom-paquet". Si la désinstallation s’est faite avec succès, vous devriez voir le mot "Succès" sur votre écran.
