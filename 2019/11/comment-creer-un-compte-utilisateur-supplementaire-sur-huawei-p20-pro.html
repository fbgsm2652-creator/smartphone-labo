Comment créer un compte utilisateur supplémentaire sur Huawei P20 Pro

3 novembre 2019PratiquesHuawei

Smartphone de haut de gamme placé sous le signe de la photo, le Huawei P20 Pro est un excellente appareil aux caractéristiques de haut vol et à la finition Premium exemplaire. Le Best Seller du constructeur chinois est animé par le Soc Kirin 970 épaulé par le GPU Mali-G72 MP12 et une mémoire RAM de 6 Go ainsi qu'un espace de stockage interne de 128 Go. Une superbe configuration qui permet de faire tourner les applications les plus gourmandes en ressources. Côté affichage, le téléphone est à la hauteur de ce qui se fait de mieux dans la catégorie du haut de gamme. Il arbore un superbe écran de technologie Oled d'une diagonale de 6.1 pouces pour une définition de 2240 x 1080 Pixels.

Le Huawei P20 Pro propose une fonctionnalité très intéressante et pratique. Cette dernière se résume par la possibilité de créer un compte utilisateur supplémentaire sur le smartphone. Cela permet à plusieurs utilisateurs de se servir du Huawei P20 Pro et de configurer l’interface comme ils le souhaitent. C'est à peu près un système multi session comme sur un ordinateur ! La configuration de plusieurs comptes utilisateurs sous Android n'est généralement pas possible sauf sur les tablettes. Le Huawei P20 Pro est une exception pour les Smartphones. Pour créer un compte utilisateur supplémentaire sur le P20 Pro, suivez les recommandation qui vont suivre.

Ouvrez les paramètres à partir de l'écran de démarrage. allez sur "Utilisateurs et comptes" puis dans "Système", sélectionnez" utilisateur " en haut. votre nom de compte est généralement en dessous. Vous verrez le menu suivant : Sélectionnez" Ajouter un utilisateur ". L’assistant de création d’un nouveau profil utilisateur démarre. Suivez l’assistant pas à pas pour ajouter un nouvel utilisateur sur le Huawei P20 Pro. Chaque utilisateur ayant sA propre session où il pourra personnaliser l'appareil et les applications.
