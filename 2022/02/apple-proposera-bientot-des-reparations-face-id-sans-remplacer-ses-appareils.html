Apple proposera bientôt des réparations Face ID sans remplacer ses appareils

26 février 2022NewsApple

Selon le site web MacRumors, les boutiques Apple Stores et les fournisseurs de services agréés par la marque pourront bientôt réparer les modules Face ID sur l'iPhone XS et les modèles plus récents sans pour autant avoir à remplacer l'ensemble de l'appareil. Le constructeur californien indique que les techniciens agréés auront bientôt accès à une nouvelle pièce pour la caméra TrueDepth. Elle embarquerait le fameux Face ID ainsi que le capteur photo avant du Smartphone, pour réparer le mobile. Selon Apple, cette décision contribuera à réduire le nombre de remplacements de téléphones complets dans le cadre de l'engagement de l'entreprise à réduire l'empreinte carbone de ses produits.

Apple a introduit le Face ID en 2017 avec son célèbre iPhone X, mais l'appareil semble être exclu des réparations. La nouvelle mesure ne s'appliquerait qu'à l'iPhone XS et et aux modèle d'après. Les Apple Stores et les réparateurs agréés Apple pourront utiliser l'outil de diagnostic Apple Service Toolkit pour déterminer s'il convient d'effectuer une réparation Face ID au lieu de remplacer carrément l'appareil. Cependant, la marque à la pomme devra former le personnel concerné sur la manière de procéder. L'entreprise annoncera bientôt les informations sur la formation en question.

De plus, un nouveau brevet présente une application Santé repensée qui pourrait signifier beaucoup pour l'Apple Pencil. Le brevet montre une application spécifique à l'iPad. Notamment, le programme est livré avec un nouveau "bloc-notes" conçu spécifiquement pour la fonction Pensil. Certains analystes estiment qu'une telle configuration semble être spécifique aux personnels de la santé. Les champs "nom " et " date de naissance " en haut du modèle et les liens vers les différentes catégories (santé et étiquettes, etc.) ressemblent beaucoup à des dossiers médicaux classique.

Étant donné que Apple Pencil peut être utilisé pour la saisie, il peut également être utilisé avec la fonction "Scratchpad". Ainsi, il y a lieu de croire qu'il peut être utilisé pour la saisie de données de santé. Ce serait formidable pour les utilisateurs si les "bloc-notes" devenaient courants dans les applications iPad. En même temps, il est très logique d'avoir un moyen de combiner les notes avec la saisie de texte. Cela pourrait le rendre utile dans les recettes, les journaux et toutes les autres applications qui traitent beaucoup d'informations.
